# 高维数组 | Multi-Dimensional Arrays

## 一、回顾与引入

在章节1.8的学习中，我们已经学习了数组的定义和使用。数组是方便存储同类型数据的集合。

例如，我们此前学习过声明一个包含5个整数的数组：

```c
int arr[5] = {1, 2, 3, 4, 5};
printf("%d\n", arr[0]);  // 输出第一个元素
```

这里的`arr`是一个一维数组，它有5个元素，是“呈一条线”的结构。

但是在实际应用中，我们经常需要存储更复杂的数据结构，比如矩阵、表格等，这些数据结构通常是二维的，甚至更高维度的。

例如，我们希望存储一个分数表：
| 姓名 | 语文 | 数学 | 英语 |
|------|------|------|------|
| 张三 |  90  |  85  |  88  |
| 李四 |  78  |  82  |  80  |
| 王五 |  85  |  90  |  92  |

有什么方法可以实现？为此我们引入高维数组的概念。

## 二、二维数组的概念

首先，我们比较变量的定义与一维数组的定义：

```c
int a;          // 定义一个整数变量
int arr[5];    // 定义一个包含5个整数的一维数组
```

在定义数组时，我们在变量名后面加上了方括号`[]`，并在其中指定了数组的大小。在声明时，方括号`[]`表示它前面的部分`arr`是一个数组，代表`arr[0]`、`arr[1]`、`arr[2]`、`arr[3]`、`arr[4]`这5个元素的集合。

考虑我们在引入时提到的分数表。要记录分数，它有3行3列的数据。我们这样考虑这个问题：
- 1. 将这个3x3的表按行分开，每一行代表一个学生的三科成绩
- 2. 单看每一行，则每一行包含3个整数。这3个整数是同类的数据，表示单科的分数，因此可以由一个一维数组来表示。例如，张三的成绩表示为{90, 85, 88}。
- 3. 现在我们有3行数据，每一行都是一个一维数组，它们也属于同类的数据。因此，如果把每一个一维数组作为一个新数组的元素，我们就得到了一个二维数组：

```c
int scores[3][3] = {
    {90, 85, 88},  // 张三的成绩
    {78, 82, 80},  // 李四的成绩
    {85, 90, 92}   // 王五的成绩
};
```

我们来分析一下这个二维数组的定义：
- `int scores[3][3]`：
  - `int`表示数组中存储的数据类型是整数。
  - `scores`是数组的名称。
  - 我们按照这样的方式拆分`scores[3][3]`：
    - `scores[3]``[3]`，后一个`[3]`提示了这是由`3`个
